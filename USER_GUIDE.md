# User Guide: Booking System

## Overview
This booking system allows two types of users:
1. **Customers** - Book services from providers
2. **Providers** - Offer services and manage appointments

## Getting Started

### 1. Registration
- Visit: https://booking-system-i95m.onrender.com
- Click "Register"
- Choose your role: Customer or Provider
- Fill in your details
- Click "Create Account"

### 2. Login
- Use your email and password
- The system automatically redirects you to the correct dashboard based on your role

## For Customers

### Dashboard Features:
- **View Available Services**: See all services offered by providers
- **Book a Service**: 
  1. Select a service
  2. Choose available date/time
  3. Confirm booking
- **My Bookings**: View, cancel, or reschedule your appointments
- **Profile**: Update your information

### How to Book:
1. Go to Customer Dashboard
2. Browse available services
3. Click "Book Now" on a service
4. Select preferred date/time from available slots
5. Confirm booking
6. You'll receive a confirmation

## For Providers

### Dashboard Features:
- **Create Services**: Add new services you offer
- **Manage Services**: Edit or delete your services
- **Set Availability**: Define when you're available for bookings
- **View Appointments**: See all upcoming bookings
- **Manage Bookings**: Confirm or cancel appointments

### How to Create a Service:
1. Go to Provider Dashboard
2. Click "Add New Service"
3. Fill in service details:
   - Service Name
   - Description
   - Price
   - Duration
4. Click "Create Service"

### How to Set Availability:
1. Go to Provider Dashboard
2. Click "Set Availability"
3. Choose dates and time slots
4. Mark slots as available/unavailable
5. Save changes

## Common Features

### Notifications:
- Receive notifications for new bookings
- Get reminders for upcoming appointments
- Email notifications (if configured)

### Payments:
- View invoices for bookings
- Payment history
- Refund requests

## Troubleshooting

### Login Issues:
- Clear browser cache and cookies
- Ensure you're using correct email/password
- Try registering again if account doesn't exist

### Booking Issues:
- Check if provider has availability
- Ensure you're logged in
- Refresh the page if slots don't load

### Service Creation Issues:
- Verify you're logged in as provider
- Check all required fields are filled
- Ensure price is in correct format
